# Cache-App

**Cache-App** is an iOS application developed using Swift, designed to emulate the core functionalities of Cash App. The app allows users to send and receive money, view transaction histories, and manage their financial activities seamlessly.

## ✨ Features

- 💸 **Send and Receive Money:** Quickly transfer funds to friends and family or receive payments with ease.
- 🧾 **Transaction History:** Access a comprehensive list of past transactions, including dates, amounts, and recipients.
- 🔒 **Secure Authentication:** Ensure user privacy and data protection with secure login mechanisms.
- 🛒 **Cash Card Integration:** Utilize a customizable debit card for in-app and online purchases.
- 💳 **Direct Deposit:** Set up direct deposit for timely and convenient paycheck deposits.

### Prerequisites

- Xcode 14 or later
- iOS 15+
- CocoaPods for dependency management
